# תנובה — חיבור טיוטות מקומיות, גרסה 133

המפרט הקובע: `asafkiri/berman-app/docs/local-first-sync.md`, נבדק מול `main` בקומיט `a77ac1c` (ברמן 137), כולל החלטת הביטול בסעיף 5.3. המודול וארבעת קובצי הבדיקות/הענן המדומה הועתקו ללא שינוי.

## מפת החיבור (סעיף 9)

- קבוצה 1: קליטה והחזרות ששמרו למסמכי `drafts/receipt` ו־`drafts/returns`. מנועי הסנכרון, השומרים והמאזינים הישנים הוסרו. לא כותבים למסמכים האלה, גם בביטול.
- קבוצה 2: הזמנה מקומית. נוספו מזהה טיוטה קבוע והערה; ניתן עדיין לשחזר את מפת הכמויות הישנה.
- שמירה מקומית: `saveReceiptDraft` / `tn_receipt_draft`, `saveReturnsDraft` / `tn_returns_draft`, `saveDraft` / `tn_order_draft`. תיקוני ההשוואה ושורות הפענוח נשמרים בתוך הקליטה; אין פענוח חוזר בשחזור.
- החלה מלאה: `handoffApply` שומר קודם למפתח המקומי, משחזר ומצייר. כשל אחסון עוצר החלפה. בכשל שמירת עריכה נשמר העותק השלם הקודם ומופיעה אזהרה.
- ארבעה סוגים נפרדים: `receiving`, `returns_weekly`, `returns_daily`, `order`. מפתחות המודול מתחילים ב־`tn_`; הנתיב מכיל `handoff_tnuva_{kind}_{sessionId}`.
- מזהה הרשומה: `receiptDraftId`, מזהה נפרד לכל סוג החזרה, `orderDraftId`. קליטות → `receipts`, החזרות → `returns`, הזמנות → `history`.
- סיום: הרשומה, סגירת handoff, יומן במזהה מושב ועדכוני מחיר מפורשים נכתבים באותה טרנזקציה. מחיר שנשתנה בשרת עוצר את כל הכתיבות. פעולות הסיום אינן נכנסות לתור הכתיבה הכללי.
- פעולות בתשלום: פענוח תמונות ומנתח AI. דגל הריצה יוצא מיד; חלון ההמתנה כולל את כל ניסיונות הרשת. מעבר מחיל את התשובה וההחלטות המקומיות ואינו שולח בקשת AI.
- צירוף נייר לקליטה שמורה: לכל עריכה `edit_{recordId}_{random}` חדש ועותק `expectedReceipt` בתוך הטיוטה. הטרנזקציה מסרבת לדרוס רשומה שהשתנתה.
- פרויקט: `tnuva-marketkiri-5d50d`; שורש: `artifacts/tnuva-app-classic/public/data`. נשמר גם שם האפליקציה בנתיב, להגנה אם השורש ישותף בעתיד.
- ביטול ישן: מקומי לפי 5.3. אין בתנובה מסמכי נייר עצמאיים להעברה לסל; `onClosed` אינו מוחק רשומות.
- מעבר גרסה: טיוטה שהייתה פתוחה אינה נתבעת בהפעלה או בציור. תביעה ראשונה רק אחרי אירוע משתמש ששינה תוכן. כתיבות ישנות של סיום מועתקות לאזור שחזור לפני הוצאתן מהתור. רשומה קיימת אינה נכתבת; עבודה חסרה נשמרת כעותק בצד עם הכמויות, המחירים ופענוח הנייר.
