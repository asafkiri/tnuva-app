# גרסה 133 — עובדים בטלפון וממשיכים בטלפון אחר

קליטה, החזרות שבועיות ויומיות והזמנות נשמרות קודם בטלפון. הגיבוי לענן רץ ברקע בלי לעצור עבודה. בטלפון אחר לוחצים **המשך אותה כאן**; העותק הראשון נעשה לקריאה בלבד. הרשומה נשמרת בענן רק בסיום, בלי פענוח נוסף בתשלום ובלי שמירה כפולה.

אחרי העדכון יש לסגור ולפתוח את האפליקציה **בכל הטלפונים** ולבדוק שבתחתית מופיע **133**. אם כתוב שהגיבוי חסום, העבודה נשארת בטלפון; נדרשת הרשאת קריאה וכתיבה ל־`drafts` בכללי Firestore כדי להעביר אותה. טיוטות ישנות נשמרות, וביטול שלהן מקומי לפי סעיף 5.3. בעיה מתקנים בגרסה גבוהה יותר, בלי חזרה לקוד הסנכרון הישן.

פירוט החיבור והבדיקות: [docs/local-first-adapter.md](docs/local-first-adapter.md).

# גרסה 132 — תיקוני ההשוואה נשמרים

תיקון כמות שהתקבלה, כמות בנייר או מחיר נשמר עכשיו מיד בטלפון. אחרי סגירה ופתיחה חוזרים לבדיקה עם התיקונים, בלי פענוח נוסף בתשלום. גם שורות שנוספו והחלטות הבדיקה נשמרות.
